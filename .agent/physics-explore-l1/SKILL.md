# Physics Explore — Level 1

## When to use

Apply this skill when the user requests **level 1** exploratory work on a physics topic, or wants a short conceptual answer without literature.

## Output requirements

1. Write **one brief paragraph** that directly addresses the question or topic.
2. **Do not** include references, citations, footnotes, or a bibliography.
3. **Do not** expand into multi-section essays, equation catalogs, or deep derivations.
4. Prefer plain language; introduce technical terms only as needed to answer the question.
5. Stay accurate and on-topic; if the question is ambiguous, answer the most natural reading in the same single paragraph.

## Format

```markdown
[One concise paragraph answering the physics question.]
```

## Anti-patterns

- Multiple sections or bullet lists as the main answer
- Equations beyond a short inline mention if unavoidable
- Any reference list or "further reading"
